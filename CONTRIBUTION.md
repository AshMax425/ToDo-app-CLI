## 🔧 Process

My workflow followed a standard open-source contribution model:

1. Forked the original repository and cloned it locally.
2. Created a dev branch to maintain a clean separation from main.
3. Created feature branches to isolate each area of work:
     - `feature/readme-installation`
     - `feature/docstrings`
4. Made incremental commits for each logical change rather than large, combined commits.
5. Pushed each feature branch to GitHub regularly for backup and transparency.
6. Opened pull requests from feature branches into `main` once the work was complete.

Tools used:
- Git + GitHub for version control
- VS Code for development
- Typer and Python's standard library for understanding code structure
- ChatGPT for guidance on errors that arose.

other issue I ran into was when adding a feature branch I got an error message when trying to push the branch. I copied/pasted that error message into ChatGPT as well and got an explanation. Once I made my first commit
